# Штрафная

Простая браузерная рулетка для мальчишника. 16 секторов: 10 готовых наказаний, 5 именных — Толик, Дима, Стас, Саня, Кирилл — и бонусное зеро. Если выпало имя, этот друг придумывает задание жениху. Если зеро — жених придумывает одно общее наказание всем пятерым.

[Открыть сайт](https://shtrafnaya-six-friends.applespring.chatgpt.site)

## Что умеет

- Крутить колесо с пониженным шансом именных секторов и редким зеро.
- Играть без повторов, пропускать задания, начинать новый круг.
- Редактировать, добавлять и отключать задания.
- Сохранять историю и настройки в браузере на одном устройстве.
- Восстанавливать незавершенный результат после перезагрузки.
- Проигрывать замедляющуюся трещотку и короткий сигнал результата.
- Мгновенно выключать звук и запоминать выбор.

Звук начинается только после нажатия. Он синтезируется в браузере через Web Audio API: скачивать аудио не нужно. При сворачивании вкладки звук прекращается; при `prefers-reduced-motion` длинное вращение и трещотка отключены.

## Шансы и круг

В исходном наборе каждый друг получает 4%, каждый готовый штраф — 7,7%, зеро — 3%. Выбор использует `crypto.getRandomValues` без смещения остатком. Размеры секторов соответствуют вероятностям, звук совпадает с пересечением их границ.

При включенном режиме без повторов обычные штрафы и имена исчезают после выпадения, в том числе при пропуске. Их шансы пересчитываются с весами 77 для штрафа и 40 для имени. Зеро проверяется отдельным розыгрышем 3 из 100 и остается с шансом 3% на каждом вращении, пока есть обычные сектора. Оно может повториться, пишется в историю и не входит в счетчик 15 секторов круга. Когда все обычные сектора сыграли, круг заканчивается; зеро не становится гарантированным последним исходом.

Можно отключить или удалить зеро в настройках. Оставить включенным только зеро нельзя. Обновление автоматически добавляет его в старое сохранение, сохраняя отредактированные задания, историю и незавершенный результат.

## Запуск

Открой `dist/index.html` в браузере или запусти локальный сервер:

```sh
node server.mjs
```

Адрес: `http://127.0.0.1:4179`.

## Проверка

```sh
node check.mjs
```

Проверяются точные вероятности, отсутствие повторов, завершение круга, соответствие стрелки результату, обновление старого сохранения, восстановление зеро, синхронизация трещотки, отключение звука и работа без Web Audio API.

## Размещение

Весь сайт — один самодостаточный файл `dist/index.html`. Загрузи содержимое `dist` на любой статический хостинг. Установка пакетов и сборка не требуются.

`.openai/hosting.json` — конфигурация текущей публикации в Sites; другому хостингу она не нужна.

Сайт ничего не переводит, не отправляет сообщения и не меняет настройки телефона. Он только показывает задания. История и тексты не синхронизируются между устройствами.
