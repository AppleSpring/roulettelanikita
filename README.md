# Штрафная

Рулетка для мальчишника: 12 готовых штрафов, Толик, Дима, Стас, Саня, Кирилл и зеро. Всего 18 секторов.

Повод для вращения выбирают друзья: викторина, спор или другая ситуация на мальчишнике. Кнопку нажимает жених, колесо выбирает наказание.

[Открыть сайт](https://shtrafnaya-six-friends.applespring.chatgpt.site)

## Общие задания

Любой по ссылке может открыть настройки, добавить, изменить или удалить задания и нажать «Сохранить для всех». Список и режим повторов хранятся в серверной базе D1 без входа. Страница получает изменения каждые 4 секунды, пока открыта, и при возвращении во вкладку.

В браузере доступны название, описание, отдельная подпись на колесе, тип «штраф / имя», включение каждого сектора, порядок и частота выпадения (целое число 1–100). Чем выше частота, тем больше шанс относительно других обычных секторов. Редактор показывает проценты для полного включенного списка. Шанс включенного зеро задан в коде: 1,5%, на каждой десятой крутке — 20%. Он не редактируется в форме и не меняется через импорт или API настроек. Исходные частоты: штраф 77, имя 40.

Последний удаленный сектор можно вернуть. Закрытие несохраненного черновика и возврат исходного списка требуют подтверждения. В разделе «Резервная копия и сброс» можно скачать JSON с заданиями, вероятностями и режимом повторов, затем загрузить его обратно. Загрузка заменяет только черновик: общая версия меняется после «Сохранить для всех». История и очередь «На потом» в копию не входят.

Если другой участник уже сохранил правки, сервер отклоняет сохранение устаревшей версии. Форма оставляет несохраненные правки и предлагает загрузить свежий список. Сохранение подтверждается только после ответа сервера. Во время вращения и до закрытия результата новое содержимое колеса не применяется.

История, выпавшие сектора и звук остаются локальными для устройства. Общие правки не стирают историю или активное наказание. Предыдущий локальный список при первом подключении резервируется в localStorage под ключом shtrafnaya-before-shared. Без связи можно играть по ранее загруженному списку; сохранение общих правок требует подключения.

## На потом

Кнопка «Записать на будущее» на карточке наказания сохраняет его в общей серверной очереди. Например, в бане выпало задание для паба — его можно отложить и продолжить вращения. Кнопка «На потом» показывает список на любом устройстве. «Выполнено» убирает задание из активной очереди для всех.

Отложенный результат сохраняет собственный текст, даже если позднее исходный сектор отредактируют или удалят. Повторное нажатие после сбоя связи не создает дубликат. Очередь переживает перезагрузку браузера и сервера. Отложенный сектор считается сыгравшим для режима без повторов, но не выполненным.

## Шансы и задания

Именной сектор дает другу право придумать наказание жениху; зеро — жениху придумать общее наказание всем пятерым. У включенного зеро шанс 1,5% на обычной крутке и 20% на крутках 10, 20, 30 и далее. Он не зависит от количества оставшихся обычных секторов. Зеро может повторяться и не расходует обычный сектор.

Все остальные шансы распределяются пропорционально частоте, заданной для каждого сектора. Размеры секторов и щелчки соответствуют шансам текущей крутки. В режиме без повторов выпавшие штрафы и имена исключаются при выполнении, пропуске и откладывании. Когда они заканчиваются, предлагается новый круг.

Счетчик вращений локальный для устройства. Увеличивается один раз при выборе результата, до анимации. Перезагрузка, повторное открытие результата и новый круг его не сбрасывают. При обновлении старой версии отсчет продолжается от доступной истории и открытого результата; более ранние очищенные круги восстановить нельзя. Очистка данных браузера или другое устройство начинают отдельный счетчик. Строка количества штрафов, имен и процента зеро под колесом убрана.

## Аниме-квиз

Отдельная страница [/quiz](https://shtrafnaya-six-friends.applespring.chatgpt.site/quiz): 30 вопросов, ответы скрыты до нажатия ведущего. Клинок — 6 средних и 4 сложных, Титаны — 5 и 5, Ван Пис — 3 легких, 4 средних и 3 сложных. Вопросы относятся к показанному в аниме, включая первую часть «Бесконечной крепости» (2025). В каждом ответе есть допустимые формулировки, серия/фильм и источник для проверки.

Каждый неверный ответ добавляет 0,5 крутки. Округление вверх происходит только после оценки всех 30 вопросов, по общей сумме. Оценки можно менять и снимать. Прогресс хранится в localStorage на устройстве ведущего, отдельно от рулетки; в крутки рулетки автоматически не переносится. Есть переход к любому вопросу, общий итог, скачивание вопросов с ответами и сброс с подтверждением. Данные — quiz-data.json; интерфейс — dist/quiz.html.

Кнопка «Изменить вопрос» открывает вопрос, ответ и пояснение для ведущего. «Сохранить для всех» сохраняет их в D1 (shared_settings, строка 2), отдельно от списка рулетки (строка 1). Остальные устройства получают обновления каждые 10 секунд и при возвращении во вкладку. Конкурентные правки защищены ревизией; несохраненный текст остается в редакторе при конфликте или ошибке связи. Можно подставить исходную формулировку. Оценки не сбрасываются. Измененные вопросы/ответы отмечаются как редакция ведущего, исходная ссылка на эпизод скрывается; исходные 30 вопросов остаются в quiz-data.json. Последняя загруженная версия вопросов кешируется на устройстве для игры без связи.

Вместо стрелки в логотипе установлена сгенерированная аниме-туфелька с прозрачным фоном. Исходник и промпт — assets/, оптимизированная версия — dist/assets/anime-shoe.webp.

Новые задания: «Пиво выбирают пацаны» и «Бокал не той рукой». У заставки, крупного шрифта, звонка и правила для бокала срок — до 23:59 сегодняшнего дня.

## Разработка

Node.js 24 и npm:

```sh
npm ci
npm run build
npm run check
npm start
```

После изменения схемы: npm run db:generate, затем проверить и закоммитить новые миграции. Локальный адрес — http://127.0.0.1:4179. Предпросмотр использует отдельную SQLite-базу .local/preview.sqlite; она не попадает в Git и не публикуется. Переменная PORT меняет порт.

Интерфейс и игровое ядро — dist/index.html, сервер — worker/index.js. Сборка встраивает HTML и ядро в самодостаточный dist/server/index.js. Звук синтезируется через Web Audio API.

## Публикация

Sites размещает Worker, создает D1-привязку DB из .openai/hosting.json и применяет миграции из drizzle. Общие задания и очередь требуют сервера: один HTML на статическом хостинге не обеспечивает синхронизацию.

Проверки покрывают вероятности, стрелку, звук, восстановление игры, перенос прежних сроков, общий CRUD, сохранность после перезапуска базы, конкурентные изменения, очередь на потом, защиту от дубликатов и общее выполнение.

Сайт только показывает и сохраняет задания: переводов, сообщений и изменений настроек телефона он сам не выполняет.
