# Штрафная

Простая браузерная рулетка для мальчишника. 15 секторов: 10 готовых наказаний и 5 именных — Толик, Дима, Стас, Саня, Кирилл. Если выпало имя, этот друг придумывает задание на месте.

[Открыть сайт](https://shtrafnaya-six-friends.applespring.chatgpt.site)

## Что умеет

- Крутить колесо с равными шансами у оставшихся секторов.
- Играть без повторов, пропускать задания, начинать новый круг.
- Редактировать, добавлять и отключать задания.
- Сохранять историю и настройки в браузере на одном устройстве.
- Восстанавливать незавершенный результат после перезагрузки.
- Проигрывать замедляющуюся трещотку и короткий сигнал результата.
- Мгновенно выключать звук и запоминать выбор.

Звук начинается только после нажатия. Он синтезируется в браузере через Web Audio API: скачивать аудио не нужно. При сворачивании вкладки звук прекращается; при `prefers-reduced-motion` длинное вращение и трещотка отключены.

## Запуск

Открой `dist/index.html` в браузере или запусти локальный сервер:

```sh
node server.mjs
```

Адрес: `http://127.0.0.1:4179`.

## Проверка

```sh
node check.mjs
```

Проверяются случайный выбор, отсутствие повторов, соответствие стрелки результату, восстановление состояния, синхронизация трещотки, отключение звука и работа без Web Audio API.

## Размещение

Весь сайт — один самодостаточный файл `dist/index.html`. Загрузи содержимое `dist` на любой статический хостинг. Установка пакетов и сборка не требуются.

`.openai/hosting.json` — конфигурация текущей публикации в Sites; другому хостингу она не нужна.

Сайт ничего не переводит, не отправляет сообщения и не меняет настройки телефона. Он только показывает задания. История и тексты не синхронизируются между устройствами.
