ШТРАФНАЯ — рулетка мальчишника

16 секторов: 10 готовых наказаний + Толик, Дима, Стас, Саня, Кирилл + зеро.
Именной сектор: выбранный друг придумывает наказание на месте.
Зеро: жених придумывает одно общее наказание всем пятерым друзьям.

Весь сайт находится в dist/index.html. Никаких зависимостей, сервера и базы.
Можно открыть index.html прямо в браузере или загрузить его на любой статический хостинг.
Случайный выбор: crypto.getRandomValues. В начале круга: каждое имя — 4%, каждый штраф — 7,7%, зеро — 3%.
Режим без повторов включен по умолчанию. Выпавшие штрафы и имена исключаются и при пропуске.
Зеро — бонус с постоянными 3% на каждом вращении; может повторяться и не входит в счетчик круга.
Остальные шансы пересчитываются по оставшимся секторам с весами 40 для имени и 77 для штрафа.
Когда все обычные сектора выпали, круг заканчивается. Зеро не становится гарантированным последним исходом.
Размеры секторов соответствуют шансам. Старые настройки, история и незавершенный результат сохраняются при обновлении.
Настройки (кнопка в правом верхнем углу): изменение текста, отключение и добавление секторов.
Изменение набора или режима повторов начинает новый круг; при наличии истории запрашивается подтверждение.
История и настройки сохраняются в localStorage только на текущем устройстве и в текущем браузере.
Звук: трещотка замедляется вместе с колесом, при новом результате звучит короткий сигнал.
Кнопка динамика в шапке и на карточке результата выключает звук сразу; выбор сохраняется отдельно от игры.
Звук синтезируется через Web Audio API после действия пользователя. Внешних аудиофайлов нет.
При сворачивании страницы звук останавливается. В режиме reduced motion трещотка не проигрывается.
Общей синхронизации между телефонами нет — играйте с одного телефона.
Перезагрузка после выбора не дает новый штраф: незавершенное наказание открывается снова.
Если браузер запрещает локальное хранилище, игра продолжится без сохранения; не закрывайте вкладку.

Проверка: node check.mjs
Локальный предпросмотр: node server.mjs
Адрес: http://127.0.0.1:4179

Никаких реальных переводов, сообщений и изменений телефона сайт не выполняет.
Он только выбирает и показывает задание. Любое задание можно пропустить.
