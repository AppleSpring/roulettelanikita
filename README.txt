ШТРАФНАЯ — рулетка мальчишника

Общий список заданий и «На потом» сохраняются на сервере для всех по ссылке.
Нажмите настройки → «Сохранить для всех». Чтобы отложить наказание, нажмите «Записать на будущее» на карточке.
Откройте «На потом» с любого устройства и отметьте выполненное.

18 секторов: 12 штрафов + 5 имен + зеро (3%). Временные задания — до 23:59 сегодняшнего дня.

Запуск: npm ci, npm run build, npm run check, npm start.
Подробности — в README.md.
