ШТРАФНАЯ — рулетка мальчишника

За что крутить — решают пацаны: викторина, спор или любой другой повод.

Общий список заданий и «На потом» сохраняются на сервере для всех по ссылке.
Нажмите настройки → «Сохранить для всех». Чтобы отложить наказание, нажмите «Записать на будущее» на карточке.
Откройте «На потом» с любого устройства и отметьте выполненное.

В настройках: тексты, имена, подписи на колесе, типы, порядок, частота штрафов и имен, повторы. Список можно скачать и загрузить обратно из JSON-файла. Изменения применяются после сохранения.

18 исходных секторов: 12 штрафов + 5 имен + зеро. Шанс включенного зеро задан в коде: 1,5%, на каждой 10-й крутке — 20%. Счетчик хранится на устройстве и не сбрасывается при новом круге. Временные задания — до 23:59 сегодняшнего дня.

Аниме-квиз: https://shtrafnaya-six-friends.applespring.chatgpt.site/quiz
30 вопросов, скрытые ответы, исправление оценок, сохранение на устройстве ведущего. Ошибка = 0,5 крутки; округление вверх только по итогу всех 30 вопросов.

Запуск: npm ci, npm run build, npm run check, npm start.
Подробности — в README.md.
